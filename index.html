TTS Live Chat — Godam UPP

Widget text-to-speech untuk live chat YouTube @godamupp. Sasarannya otomatis: live yang sedang berjalan saat itu — kalau lagi nggak live, ya tidak ada yang dibacakan. Komen dibacakan mengikuti profil suara Majestic Throne, suara dubbing Shorts Godam UPP. Jalan sebagai OBS Browser Source, tanpa install aplikasi apa pun.

Versi 11 (23 Nov 2026) — bacaan lebih cepat.

Belum jalan

1 Kontrol

Widget ini jalan sendiri sepenuhnya: begitu halaman dimuat, sistem langsung mencoba mengaktifkan suara dan mulai membaca data live @godamupp yang diisi pengawas Muse tiap 30 detik — begitu live muncul, chat langsung dibacakan tanpa klik apa pun. Satu-satunya tombol di widget ini adalah Matikan Sistem di bawah: mematikannya menghentikan semua pembacaan data, polling, dan bacaan. Nyalakan lagi kapan saja dengan tombol yang sama.

Suara belum aktif — sistem sedang mencoba mengaktifkan otomatis.

Pengawas: MATI.

2 Sambungkan ke Live

NOL kuota — widget ini tidak memakai YouTube Data API sama sekali; data live + chat diisi pengawas Muse, API key tidak dibutuhkan. Pengawas mengecek live @godamupp dan menulis hasilnya ke file live.json + chat.json; widget hanya membaca kedua file itu. Live yang dituju selalu live yang sedang berjalan di @godamupp — tidak ada pilihan video manual, dan tidak ada yang perlu diisi.

Belum dicek
Widget menyasar live yang sedang berjalan di @godamupp. Kalau sekarang lagi nggak live, ya belum ada live yang bisa dituju — begitu kamu live, pengawas langsung menyasar live itu sendiri.

Widget membaca live.json tiap 30 detik selama sistem nyala; kalau live sedang berjalan, widget membaca chat.json tiap 5 detik dan membacakan pesan barunya — tidak ada langkah pilih-pilih video. Kalau data pengawas lebih tua dari 3 menit, baris Pengawas memberi peringatan (pengawas mungkin mati) — saat itu tidak ada yang bisa dibaca sampai pengawas jalan lagi.

3 Suara

Profil suaranya mengikuti Majestic Throne — suara dubbing Shorts Godam UPP (Bahasa Indonesia, speed 130). Suara itu dirender jadi file audio waktu produksi Shorts dan tidak tersedia sebagai suara di browser, jadi chat live — yang teksnya baru muncul pas live — dibacakan langsung oleh suara Indonesia browser di bawah, dengan tempo & pitch disetel mengikuti profil Majestic Throne (tempo 1,30×, pitch 0,90).

Rekaman contoh pakai suara Majestic Throne asli di speed 130, persis setting dubbing Shorts: “Halo guys, ini suara Majestic Throne, suara dubbing yang dipakai di Shorts Godam UPP. Pas live nanti, komen kalian bakal dibacain pakai gaya suara ini. Gas, kita mancing!”

    Riwayat pesan yang masuk, dibaca, dilewati, dan kejadian penting selama sesi ini.

      Belum ada aktivitas.

      Panduan

      Jujur dulu: widget ini sudah teruji di live sungguhan 23 Nov 2026 (live @godamupp terdeteksi, chat masuk dan terbaca). Catatan v10: widget ini membaca data yang diisi pengawas Muse — kalau pengawas mati atau YouTube mengubah sistem web-nya, widget tidak bisa membaca chat sampai pengawas jalan lagi. Pesan bisa telat ~10–20 detik dari waktu dikirim (pengawas membaca chat tiap ~10 detik, widget membaca file chat tiap 5 detik).

      A. NOL kuota — cara kerjanya (tanpa API key)

      Widget v11 tidak memakai YouTube Data API sama sekali, jadi tidak ada kuota yang terpakai dan tidak ada API key yang dibutuhkan — key lama yang mungkin masih menempel di URL Browser Source diabaikan. Cara kerjanya: pengawas yang jalan di mesin Muse mengecek live @godamupp dan membaca chat-nya lewat sistem web YouTube, lalu menulis hasilnya ke dua file di repo GitHub tts-godam-upp — live.json (lagi live atau tidak, tiap ~60 detik) dan chat.json (50 pesan terakhir, tiap ~10 detik saat live). Widget ini hanya membaca kedua file itu dari raw.githubusercontent.com — live.json tiap 30 detik, chat.json tiap 5 detik saat live. Kalau pengawas mati, baris Pengawas memberi peringatan dan widget menunggu sampai data baru masuk. Cadangan kalau pengawas mati lama: widget v8 (pakai API key + YouTube Data API resmi) masih ada sebagai cadangan.

      B. Langkah tes (wajib urut)

      1. Buka widget ini di Chrome dulu (bukan langsung di OBS). Tidak ada yang perlu diisi — sistem langsung membaca data pengawas. Suara dicoba aktif otomatis oleh sistem.
      2. Dengarkan contoh suara Majestic Throne di panel Suara. Tes bacaan chat dilakukan lewat live sungguhan (langkah 3) — panel tes chat sudah dihapus sejak v7.
      3. Saat live beneran: sistem yang nyala otomatis membaca data pengawas dan langsung menyambung ke chat live @godamupp tanpa klik apa pun — kalau saat halaman dimuat kamu lagi nggak live, widget mengecek ulang tiap 30 detik dan mulai sendiri begitu live muncul di data pengawas. Lalu kirim komen dari HP/akun lain dan dengarkan apakah dibacakan (pesan bisa telat ~10–20 detik). Satu-satunya tombol yang ada adalah Matikan Sistem — pakai itu kalau mau mematikan seluruh sistem.
      4. Kalau di Chrome sudah beres, baru pasang di OBS (langkah C). Tidak ada key yang perlu diisi di OBS — pengawas yang mengisi datanya.

      C. Pasang di OBS

      1. Di OBS: Sources → + → Browser, tempel URL widget ini dengan tambahan ?obs=1 di akhir alamatnya untuk tampilan minimal transparan.
      2. Di properti Browser Source, centang Control audio via OBS.
      3. Di Advanced Audio Properties (klik kanan sumber audio widget), set ke Monitor and Output — persis seperti Saweria dulu — supaya kamu dengar di headset dan penonton juga dengar.
      4. Klik kanan Browser Source → Interact kalau mau melihat status/pengawas dari dalam OBS — tidak ada yang perlu diisi; sistem jalan sendiri.
      5. URL lama yang masih berisi ?obs=1&key=…: parameter key-nya diabaikan di v10 — boleh dibiarkan, boleh dihapus. Widget v9 tidak memakai API key sama sekali.

      D. Catatan suara

      • Suara dubbing Shorts Godam UPP adalah Majestic Throne (Bahasa Indonesia, speed 130) — rekaman contoh aslinya ada di panel Suara. Suara itu dirender jadi file audio saat produksi Shorts dan tidak terpasang sebagai suara browser, jadi bacaan chat live memakai suara Indonesia dari browser dengan profil yang disetel mengikutinya: tempo 1,30× dan pitch 0,90. Geser slider Kecepatan / Pitch kalau mau disesuaikan lagi.
      • Daftar suara mengikuti browser/sistem yang membuka widget: Chrome biasanya punya “Google Bahasa Indonesia”; di macOS ada “Damayanti”. Di dalam OBS, suara yang tersedia bisa berbeda dari Chrome — itu sebabnya tes di Chrome dulu, lalu cek lagi di OBS.
      • Kalau tidak ada suara Indonesia sama sekali, widget tetap menampilkan semua suara yang tersedia supaya tetap bisa dipilih manual.
      • Pesan dari Super Chat juga dibacakan; stiker Super Chat dan notifikasi member tidak punya teks pesan, jadi dilewati.
